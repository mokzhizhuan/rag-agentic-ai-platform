# Phase 9.3 Equipment Maintenance Manual

Document ID: KB-TEST-9301
Equipment: Meridian Sensor Unit M-42
Maintenance interval: Every 45 days
Maximum operating temperature: 68 degrees Celsius
Calibration officer: Sample Engineer Rowan
Emergency shutdown code: QZ-4826

## Maintenance Procedure

1. Disconnect the unit from its test power source.
2. Inspect the external housing.
3. Clean the sensor surface.
4. Verify calibration readings.
5. Record the maintenance results.

## Troubleshooting

If the sensor reports error E-17, inspect the communication cable.
If the sensor reports error E-22, repeat the calibration procedure.
